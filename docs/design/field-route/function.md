# 真实影像田块航线设计

首个案例在作业平台验收。飞手在没有开发人员提示的情况下，能用影像确认田块和排除区，逐段复核喷洒与停喷，比较同一田块的候选航线，并说明选用、退回或暂缓的理由。官网复用通过验收且获准公开的案例资料，使用作业平台确认的航段、指标和说明。

## 从影像确认田块

- 影像提供可核对的田埂、道路和地物。航线使用飞手确认并保存的矢量田界和排除区。可以从测绘数据导入，也可以在有地理配准的影像上描绘，两者均记录来源、采集日期和确认人。
- 影像需记录提供方、采集日期、覆盖范围、原始坐标参考系、像素到地面坐标的变换、分辨率、配准误差和公开授权。地图上可开关影像及各矢量图层，核对分散在田块不同位置的可辨识地物，记录偏差点和采用的容差。容差由案例按影像和边界精度、作业所需净距确定。缺少配准、影像覆盖不全或偏差超限时，显示原因和位置，田块保持待确认，阻止基于该影像生成航线。修正相应影像或矢量来源后重新确认。
- 田界为单外环闭合 GeoJSON Polygon，排除区以独立多边形保存，关联到同一田块。存储坐标为 WGS84 十进制度 `[经度, 纬度]`，Leaflet 接口使用 `[纬度, 经度]`。影像按实际坐标参考系变换后对齐，禁止把屏幕像素直接当地面坐标。计算沿用现有首个田界顶点为原点的局部东西、南北平面，长度和退让为米，面积为平方米，时间为秒，速度为米每秒，流量为升每分钟，高度为距冠层米。航向从正北顺时针计度，轴向候选按 180° 去重，实际每段仍保留行进方向。重叠参数是百分数。
- 每处排除区记录是仅禁喷、禁飞，还是两者，并保存来源和相应退让。规则缺失时标待确认。现有裁剪对传入的区统一约束喷洒中心线，方案复核还须按区规则检查喷幅和转移路径。

## 航向和航段

先按田界退让与排除区退让计算目标区，再复用当前平行扫描裁剪。扫描线数量取横向宽度除以名义间距后向上取整，名义间距为喷幅乘以一减重叠比例。扫描线在投影宽度上均匀居中分布，相邻行往返。现行代码过滤不长于 0.05 米的喷洒段和短于 0.001 米的连接。候选方案使用相同边界、排除区、喷幅、起点设置和指标口径。

| 方案 | 航向与生成方式 | 适用条件与取舍 |
| --- | --- | --- |
| A，南北向直连基线 | 0°，原样使用 `generatePlan`。 | 保留飞手指定方向，容易复现。停喷直连可能穿过排除区或田块凹口。 |
| B，东西向直连 | 90°，同一裁剪与蛇形顺序。实际案例可用与主轴近乎垂直的方向作对照。 | 单独检验改变航向的影响。田块横向扫描行较少时，凹口仍可能切出更多分段。 |
| C，南北向避让连接 | 0°，只在禁飞区附近按确认的净距缩短受影响的喷洒端点。保留扫线顺序，停喷直连有冲突时，在允许飞行区域内用边界与缓冲区拐点作候选，搜索最短可见折线。每条边都检查净距。 | 便于定位绕行增加的距离和缺口。找不到合法连接时标出断点并阻止确认。折线只是平面候选，转弯是否能飞仍需核实。 |

每段输出顺序、起终点、长度、时长和喷洒状态。喷洒段 `spray=true`，连接、绕行和已指定起点到首段的转移均为 `spray=false`。任务对应 `spray_enabled`，停喷段 `planned_flow=0`。绕行每条折线边单独保留停喷标志，地图以虚线显示并能按段定位。现有任务包 `aeroguard-mission/1.0` 是 WGS84 航点与航段的交换格式，标有 `requires_vendor_conversion=true`。本案例单独标明调头、起降和返航是否纳入规划，未纳入的部分留给飞手复核。

## 同田对比与验收样例

### 正常样例

以 WGS84 原点 `[120,30]` 为参考。下列顶点用局部 `(东, 北)` 米表示。复跑时使用现有 `toWgs84` 转为 GeoJSON 经纬度。

- 凹形田块闭合环为 `(0,0) → (60,0) → (60,40) → (40,40) → (40,20) → (20,20) → (20,40) → (0,40) → (0,0)`，面积 2,000 m²。
- 同一处禁喷且禁飞区为 `(12,4) → (18,4) → (18,16) → (12,16) → (12,4)`，面积 72 m²。田界和该区的喷洒退让均为 0 m，几何目标区为 1,928 m²。允许飞行区域设为田界闭包，禁飞区内和边界均不得通过，C 在禁飞区四周取 1 m 最小净距。该净距仅供样例验算。
- 喷幅 11 m，输入重叠 0%，距冠层高度 3 m，速度 5 m/s，使用自动起点，不计返航。测试环境将影像和田界确认状态设为已通过，以单独验证几何。
- 每个喷洒段用以中心线为轴、宽 11 m、平头的矩形表示名义喷幅，先取全部矩形并集。缺口是目标区减并集，区域外覆盖是并集减目标区，另列禁喷区内的并集面积。重复覆盖量为各矩形与目标区的相交面积之和减并集在目标区内的面积，重复两次记一次增量。转移距离累加停喷段长度。田界上行走允许，穿出田块或接触禁飞边界按冲突记录。喷幅越过作业目标的面积另列，零冲突仍须检查这项指标。本口径只表示平面名义喷幅，实测沉积和风漂移另行验证。

| 方案 | 喷洒段数 / 长度 | 覆盖缺口 | 区域外覆盖 / 其中禁喷区 | 区内重复覆盖量 | 停喷转移距离 | 路径冲突 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| A | 7 段 / 188 m | 36 m² | 60 / 0 m² | 116 m² | 62 m | 1 段穿禁飞区 |
| B | 8 段 / 188 m | 45 m² | 57 / 0 m² | 128 m² | 82 m | 2 段穿禁飞区，2 段穿田界凹口 |
| C | 7 段 / 186 m | 54 m² | 60 / 0 m² | 112 m² | 72 m | 0 |

A、B 的喷洒端点和转移取自现有 `generatePlan`，面积按上文矩形与多边形布尔运算复算。此整数坐标样例的面积计算以回投影后舍去浮点尾差的端点为准。A 由西往东扫 `东=5,15,25,35,45,55` 米，禁飞直连为 `(15,16) → (15,4)`。B 从北往南扫 `北=35,25,15,5` 米，在 35、25 米两行跨凹口，在 15、5 米两行跨禁飞区。C 按 A 的段序复算，把对应喷洒端点改到 `(15,17)` 和 `(15,3)`，用等长候选中的东侧路线 `(15,17) → (19,17) → (19,3) → (15,3)`，三段全停喷。C 是设计计算结果，现行规划器仍输出 A 型直连。验收时按表检查段数和冲突数，距离、面积允许与表值相差 0.01 m、0.01 m²。比较界面应显示 A、B 的冲突段及原因。A、B 可用于比较，存在硬冲突时禁止选定。C 的平面航迹检查通过。区域外覆盖和缺口满足飞手确认的案例限值后，方可选定并进入逐段复核。

### 失败样例

沿用正常样例的田块、排除区、影像确认状态和参数，只把田界退让由 0 m 改为 21 m。预期向内退让后无可喷洒区域，现有规划函数返回 HTTP 状态语义 400、错误码 `INVALID_INPUT`、提示“退让后没有可喷洒区域”。页面保留田界与当前设置，提示检查退让值，当前输入不产生航段、覆盖指标或任务。修改参数当下，先前方案及其预测、复核和导出资格已失效，生成失败后仍维持该状态。

## 结果失效与复核

- 确认记录绑定影像来源及配准、田界和排除区的标识与内容。替换影像、修改配准、边界、区种类或退让时，相关确认、候选与复核失效。回到对应确认步骤后重新计算。
- 候选和指标还绑定起点、航向、喷幅、重叠、高度、速度、允许飞行范围与净距、算法和指标口径。任一相关输入变化即标记旧结果为历史并阻止继续复核、导出或挂到当前报告。平移、缩放、开关图层不触发重算。加载缺少依赖记录的旧方案时提示重新生成。异步结果写入及导出前再次比对当前输入，防止较早的计算覆盖较新的方案。
- 下游预测和报告绑定具体方案及其输入。风况、流量、喷头标定等改动使依赖这些值的预测、任务或报告失效。若标定同时改变有效喷幅，航线及复核也要重做。保留历史输入和结果供回查。

| 平台可检查的几何约束 | 飞手需确认的现场条件 |
| --- | --- |
| 坐标值、闭环、自交、非零面积、投影后的跨度，排除区归属和退让输入。沿用田块现行 4–1000 个坐标（含闭合点）、面积大于 1 m²、东西及南北跨度各不超过 2 km 的限制。 | 影像和实地是否对应，田埂、作物边缘、敏感地物、边界归属是否正确，影像之后是否有变化。 |
| 扫描线裁剪、喷洒段中心线是否在允许喷洒区域、名义喷幅与禁喷区相交面积，停喷标志及连续性，转移段与已录入禁飞区和允许飞行边界的关系。 | 电线、树木、人员和临时障碍，调头净空、转弯能力、地形及距冠层高度，起降与返航条件，现场风况、有效喷幅、喷头开关延迟和停喷实际效果。 |

真实案例还缺影像及公开授权、独立地面核对点及其精度、确认后的矢量田界与排除区、机型和转弯资料、障碍与起降信息、喷幅及停喷响应标定、现场天气、允许的覆盖缺口和区域外覆盖限值。缺项在复核页用具体字段显示，所需证据补齐后才记录对应条件通过。

验收时，飞手应独立完成田界确认，对同一影像和边界查看至少两个航向候选，在共同尺度下读取缺口、区域外及重复覆盖、转移距离和冲突，点选检查每个喷洒段和停喷段，并保存选定方案或退回理由。验收人按正常与失败样例核对数字和拦截行为，再实际修改一处排除区或规划参数，验证旧结果失效。真实案例通过后保留确认输入、候选指标、逐段复核和选用理由；官网使用其中可公开的影像、边界、航线、指标及来源说明。
