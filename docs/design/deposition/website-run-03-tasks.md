## 沉积显示和验收

- [ ] **确认官网可用素材。** 从已选 run-03 读取 `input.json`、`results.json` 和 `route-visual-display.json`。对照官网田块航线设计中的案例复核与公开素材记录，确认航线图、底图、田界和署名的可用范围。官网按需加载精简数据和已有图件。
- [ ] **统一坐标和颜色。** 在本地东、北、上坐标对齐田界、航线和贴地纹理。显示网格为 0.3 m，采用标准差 0.45 m 的归一化高斯核，按 run-03 构建器的 3σ 参数取离散核半径。复用蓝至黄的色带和低浓度渐隐。湿喷液固定 0–15 g/m²，非挥发示踪物固定 0–0.02 g/m²。以同一位置、同一工况和同一质量层核对二维图与三维贴地纹理。
- [ ] **核对指标和色块来源。** 田内外比例以各自喷出的组分质量为分母。漂移 P95 指各粒子释放点到落面的水平距离，以落面示踪物质量加权取第 95 百分位。案例图层使用高斯平滑显示，指标读取粒子质量统计。联合工况基准读数为水蒸发 7.3%、田内示踪物 97.92%、田外示踪物 2.07%、漂移 P95 22.1 m。
- [ ] **沿用回放规则。** 官网案例需要时间回放时，使用现成的航段时间与落面事件。喷洒段释放，转场停喷，液滴落面后才进入累计纹理。沿用官网单机体和镜头，代表液滴采用 run-03 已筛选的较大粒径样本和 0.55 s 短轨迹。验收时检查首段喷洒、相邻航段转弯、非喷洒转场和全航线结束四个时点。二维和三维对齐同一时间与数据。
- [ ] **在审核 demo 逐页验收。** 顺序为 Physics 与 Model、Mapping、Wind 与 Lab、其余入口和页面。检查桌面及窄屏下的控件、图例、可读性和导航，用相同工况对照 run-03。官网更新以审核通过的内容为准。
