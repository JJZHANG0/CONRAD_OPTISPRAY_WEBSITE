# 沉积模型设计

沉积预测用于作业平台比较同一田块的喷洒方案。首个真实影像案例由飞手独立确认田块、复核航线、比较方案。影像提供地理位置和现场背景。沉积、漂移和蒸发的准确性分别用仿真对照和实测评价。官网复用通过平台验收的案例及其证据说明。

## 耦合方案

统一采用局部东、北、上坐标，明确气象风来向、影像投影和高度基准。释放位置来自喷洒航段、喷头偏移与姿态，释放质量来自流量、液体密度和喷洒时间。数量谱按粒径立方换算质量权重，体积谱直接按体积分配，同一对照使用同一粒子释放样本。需要明确粒径谱是在喷嘴出口还是下洗影响后的截面测得，避免把二次破碎重复计入。

| 方案 | 做法与数据 | 用途 |
| --- | --- | --- |
| 旧模型与单项近似 | 原样保留默认结果。旧蒸发筛选只用于对比历史数据。可用常数垂向下洗做诊断，需已知代表高度速度及范围。 | 快速定位蒸发或落时变化，无法描述空间下洗、部分蒸发或横向卷吸。 |
| 解析流场与粒子单向耦合 | 将环境风和随无人机移动的下洗速度场相加，按局部气滴相对速度更新阻力和蒸发。需粒径谱、初速和喷角、温湿度和压力、配方挥发分与残余物性、旋翼位置和尺寸、转速或推力、飞速和离落面高度、至少两高度的下洗速度剖面。 | 首选候选。可独立关停任一项，在平台预算内计算。 |
| 离线 CFD 流场驱动粒子 | 用冻结流场插值替代解析下洗，保留同一粒子积分和统计口径。需原始网格、风场与湍流字段、边界条件、旋翼参数、采样时间、坐标映射及场外规则。总流场已含风或下洗时直接使用，避免叠加。 | 用于复杂流场对照，也可在近场用 CFD、远场用环境风，在匹配区检查速度连续性。 |
| 气液双向耦合 | 粒子反向给气相增加动量、水汽和能量源项。需喷雾局部负载、液滴温度和换热数据、非稳态流场及计算资源。 | 当高负载或自增湿导致单向模型出现稳定且可测的误差时评估。 |

候选模型逐步更新粒子位置、速度、液滴直径、溶剂质量和非挥发物质量。用 D² 定律作为起点，每步按温湿度和相对速度修正蒸发速率，阻力使用更新后的尺寸与物性。液滴到达干残余直径后继续追踪残余物，纯溶剂完全蒸干时结束该粒子。先采用稀喷雾、露天、近平地和单一参考落面假设。碰撞时按穿越落面的时刻归类。冠层顶面的到达量称为冠层顶沉积潜势。叶面截留、冠层穿透和地面通量需要单独建模和采样。

## 成对工况

| 工况 | 蒸发 | 下洗 | 比较任务 |
| --- | --- | --- | --- |
| 基线 | 关 | 关 | 分别锁定 Python 默认喷嘴射流计算和平台终端沉降计算。候选实现的双关输出做向后兼容检查。 |
| 仅蒸发 | 开 | 关 | 对基线比较落时、部分挥发质量、干残余去向和细滴终点。旧蒸发开关作为独立历史诊断。 |
| 仅下洗 | 关 | 开 | 对基线比较垂向速度、落时、喷幅和田外落量。喷嘴初速保持一致。 |
| 联合 | 开 | 开 | 分别对两种单开工况比较。每项指标另报联合值减去两个单开值再加基线值，量化交互。 |

每套引擎内部成对固定航段、喷幅、粒径样本、风样本、温湿度、粒子数、网格和计算域。跨引擎对照使用显式共享释放表，统一风向、落面和输出口径。至少覆盖无风无下洗、干热与高湿、稳定低风与参考高漂移、细谱至粗谱、边界附近喷洒、零流量、无沉积和颗粒出域。下洗可能缩短落时，同时改变相对速度及扩散。联合效果以分项结果和误差为准。

## 输出和验收

质量从喷出时入账，按湿喷液和非挥发示踪物各记一套。湿质量等于田内沉积、田外沉积、已蒸发溶剂、离开计算域时的剩余湿质量和结束时仍悬浮湿质量之和。示踪物同样归类，蒸发项为零。每粒子只按一次终止状态归类，部分蒸发随步累计。物理出域与网格显示裁剪分开记录，平滑前后做质量核对。比例以各自喷出质量为分母，零流量比例及无沉积的漂移分位数记为不可计算。

漂移统一输出相对释放位置的水平位移，另报沿下风向的有符号距离、田外沉积占比、出域占比和下风向样带沉积。落点 P95 按该账本的已沉积质量加权，记录采用湿质量还是示踪物，以及最大漂移和有效落样量。历史结果保留各自统计定义。沉积按田内外质量比例、单位面积质量、分区分布和变异系数报告，统一网格尺度、掩膜和单位，零沉积地块计入田内均匀性，均值为零时变异系数不可计算。

下表门槛用于阶段评审。百分点表示两个百分比直接相减。新设阈值是待冻结的工程目标，均需在看验证结果前确定。

| 验证层 | 参考与复算 | 放行条件 |
| --- | --- | --- |
| 数值回归 | 用原 Python 回归及平台 `app/tests/model.test.ts`、`app/tests/prediction-extra.test.ts` 锁定旧接口，补双关快照及四工况边界测试。对同一释放表分别减半步长和网格间距、增加粒子数并用多种子确认采样波动。 | 新账本相对闭合残差每工况 ≤0.1%，质量非负且无重复归类。开关关闭时对应源项为零。兼容模式固定环境和输入的确定性输出与基线一致。加密后田内外占比与蒸发量各变化 ≤1 个百分点，P95 变化 ≤较大者（0.5 m、基准 P95 的 5%）。 |
| 计算流体力学（CFD）对照 | 先复核冻结参考四谱；补齐原始算例后生成同样的四工况及至少一个独立案例。核对参考蒸发字段是否表示溶剂损失、完整液滴消失或其他流失，核对漂移样本和分母。按相同落面、航线、粒径分布和掩膜重采样。 | 匹配口径后，建议逐案例逐谱检查漂移 P95 绝对误差 ≤较大者（2 m、参考值的 20%），田内外沉积占比各 ≤10 个百分点，蒸发占比 ≤10 个百分点。对照下洗剖面、落点图、最大漂移和样带，报告偏差及数值不确定度。缺少原始标签定义或可比样本的项列为待核对。 |
| 田间验证 | 先用可控环境测单因素下洗剖面和液滴缩径或称重损失。田间用已知浓度的非挥发示踪物与可定量回收的收集器，配合空白和回收校正。水敏纸补充覆盖率和斑点空间分布。田内设网格，田外沿下风向分距布点，采样延伸至信号接近检出限，记录风和采样不确定度。 | 沿用已有校准计划的田内占比误差 ≤15 个百分点，并建议田外占比 ≤10 个百分点、可直接估计的漂移 P95 误差 ≤较大者（2 m、实测值的 20%）。测不出全域漂移 P95 时预先采用样带累积示踪量和达到累计 95% 的距离，注明其采样范围。至少三个风速档、每档三次独立重复，每场景规划田内外合计至少 30 点，按方案和工况报告重复间差异及区间。方案差值落在观测或模型不确定范围内时显示差异未分辨。 |

田间占比由同口径的采样估算与喷出示踪总量计算，记录外推面积、检出限、回收率和缺测。未回收示踪物保留为未解释质量，不能由水敏纸覆盖率反推蒸发。若一级证据不足，保留差距，下一层的参考数据另行评估。校准参数和阈值锁定后，用独立日期或地块做留出验证，复用同一条航线的样点不当作独立飞行。

## 复算与首案交付

- Python 历史校准入口为平台仓库下 `python tools/calibrate_physics.py`，默认写入已有校准 JSON，复算应在独立工作副本执行。保存 Python、NumPy 和平台运行时版本、源码提交及本地依赖内容哈希、输入与输出哈希、种子、时间步、计算域、终止规则、网格与阈值。保留原始输出及统一口径的对照表。
- OpenFOAM 补齐数据集清单、原始案例 `case.json`、求解器及配置、网格和边界条件、流场时间步、`labels/metrics.json` 与落点网格、质量与收敛日志、构建脚本依赖。以配对包案例编号和输入哈希对齐。记录域大小与田界、高度相对地面或冠层、风向坐标、粒径谱基准及参考标签质量分母。原始资料不足时，结果状态为冻结参考对照。
- 首案优先补齐影像日期、投影和定位误差、飞手确认的田界和障碍物、喷洒段与转弯段、轨迹时间戳和喷头高度、气象测点高度、同步温湿度和风、设备与配方、粒径谱、流量校验、下洗实测剖面及沉积采样。缺关键输入时，沿用可复算基线并展示缺项和假设，候选模型仅展示情景比较。
- 飞手验收时，由未参与实现的飞手独立完成田界确认、查看相对地面或冠层的航高和边界退让、核对喷洒与非喷洒航段，并比较至少两个方案的田内均匀性、田外漂移和证据等级和不确定性。报告应能从方案追溯到输入、工况和证据等级。通过工作流验收后官网可复用获准公开且带证据标注的案例，涉及实测精度的陈述须有对应田间结果。

## 适用范围与后排事项

首期限单机、已知喷头和粒径谱、可观测的气象条件、近似平坦田块和可定义落面的作业。输出用于同场景方案比较。适用参数范围由独立验证覆盖的设备、配方、风、温湿度和航高组合确定。超出范围时标记外推，缺输入或差异无法分辨时保留相应状态。药效、施药合规与安全缓冲距离需要独立依据。

外围扩展可后排，包括桨叶解析和全耦合非稳态 CFD、复杂地形与多机尾流、冠层内多层截留与叶面反弹、二次破碎和碰并、代理模型重训与区间重校准、在线气象接入、三维粒子动画和官网交互展示。首批先完成两套基线、统一账本及四工况的复算，再按数值回归、CFD 对照和田间验证分别放行。
